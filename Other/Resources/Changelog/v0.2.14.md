# Release notes

## Changes

- The scripts of the codeunits now use the current api of ScriptCollection (the api "TasksForCommonProjectStructure" which they used does not exist anymore, so they were not runnable)
- Updated the versions of the used images
- Removed the configuration of GitVersion, which is not used anymore
- Updated Bitcoin Core from v28.1 to v31.1
- Bitcoin Core is now downloaded from bitcoincore.org (bitcoin.org does not provide all releases) and verified against the published sha256-checksums
- The arm64-image now contains the arm64-binaries of Bitcoin Core (before, it contained the x86_64-binaries, so it was not runnable)
- The update of the Bitcoin-dependency only considers released versions (versions which only have release-candidates are ignored)
- bitcoind now runs as main-process of the container, so `docker stop` triggers a clean shutdown of the node
- Removed the unused package `wget` from the image
- Replaced the task to run the example by tasks to start and stop the example
- Added the reference-documentation
